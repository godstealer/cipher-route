安装只需几步

  1. 解压下载包，保留解压后的文件夹。
  2. 打开 Chrome / Edge 的扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”，选择含 manifest.json 的扩展目录。完整包中是 extension 文件夹。
  3. 仅完整安装：Windows 双击 Install.cmd；macOS 双击 Install.command；Linux 在包目录运行 sh install.sh。默认注册 Chrome 和 Edge，无需填写 ID。
  4. 回到扩展点击“检测本地内核”。使用自定义 TLS 前，在“查看 CA 信息”核对证书并手动信任。普通代理不需要此步骤。

浏览器不能代你执行安装文件。macOS 未签名安装包可能需要系统安全确认。Linux 以 Ubuntu 22.04 为基线；Snap/Flatpak 浏览器暂未适配。Windows/Linux ARM64 暂无安装包。
